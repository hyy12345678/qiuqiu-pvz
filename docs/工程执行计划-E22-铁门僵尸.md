# E22 执行计划（新僵尸：铁门僵尸）

> 日期：2026-11-24
> 起因：作者选择「加僵尸」。前面评估过：现有 6 种僵尸只在血厚/血薄/速度快三个维度变化，
> **缺少改变玩家策略的类型**。
> 性质：**新内容**，同时是第一个引入「伤害类型」机制的设计。

## 1. 设计：为什么是铁门

现有僵尸的"策略性"其实只有两条：

| 僵尸 | 玩家要做的 |
|---|---|
| 路障 / 铁桶 | 堆更多火力（纯粹的血量墙） |
| 撑杆 | 提前留出空位，或者用坚果挡 |
| 报纸 | 注意破防后的狂暴 |

**没有一个逼你更换火力配置。** 铁门僵尸补的就是这一格：

> **铁门只挡弹道伤害。** 豌豆、小豆、寒冰、双发、球球子弹全部无效；
> 樱桃炸弹、土豆雷、球球导弹、迪迦光线、火豌豆的溅射、小推车照常生效。

它不改变血量（200+900），改变的是「你带的那套豌豆炮台对它没用」。

## 2. 实现

### 2.1 伤害网关

`damageZombie(world, z, d, pierce)` 增加第四个参数：

- `pierce` 缺省 `false` —— 弹道伤害，会被 `z.screen` 挡住，**不掉血也不掉护盾**；
- `pierce=true` —— 爆炸/光线/推车/火焰溅射，照常结算。

挡住的瞬间置 `z.screenHitT = 0.12`，渲染层据此画火花。
**这个反馈是必须的**——没有它，玩家会以为"子弹没生效"而不是"被挡住了"。

### 2.2 哪些调用点传了 pierce

| 伤害来源 | pierce | 理由 |
|---|:---:|---|
| 豌豆 / 冰豆 / 孢子 / 球球子弹 | ✗ | 就是被挡的那一类 |
| 樱桃炸弹 `explode` | ✓ | 爆炸 |
| 球球导弹 `explodeMissile` | ✓ | 爆炸 |
| 火豌豆的溅射 | ✓ | 火焰绕过门缝 |
| 迪迦光线 | ✓ | 贯穿一切 |
| 小推车 | ✓ | 碾压 |

### 2.3 绘制

- 实体：拱形铁盔 + 铆钉 + 三根竖向加强筋，与铁桶（圆桶）在轮廓上明确区分；
- 火花：径向亮斑 + 5 点火星，位置由 `screenHitT` 推出（**不用随机数**，否则绘制轨迹每次不同会红）；
- 图鉴头像与菜单展示同步支持。

## 3. 踩到的问题

**菜单那排僵尸是写死的类型列表**，新僵尸没自动进去。第一次截图发现"菜单里没有铁门"，
补上后又发现**位置选错**：最右边会被"全部关卡"按钮和报纸僵尸挤住，只露半个。
最后挪到球球右侧的空草坪（x≈612）才完整可见。

**图鉴提示必须写明机制**。如果只画个铁盔不说"挡弹道"，玩家会以为是美术差异而不是规则差异。
已加一行：`铁门僵尸：铁门挡豌豆！用樱桃炸弹 / 土豆雷 / 火豌豆破门。`

## 4. 关卡投放

| 关 | 是否出现 | 权重 |
|---|---|---|
| L1 / L2 | 否 | — |
| L3 | 是 | 1（稀客） |
| L4 | 是 | 1 |

放在 L3 才开始：让玩家先熟悉其他机制，再引入"火力必须换"的约束。

## 6. 未验证 / 遗留

- **平衡未实测**。900 护盾 + 完全免疫弹道，在"只带豌豆"的阵容下等于无敌。
  实际难度取决于玩家是否带了樱桃/土豆雷——**这需要真人试玩**。
  如果太劝退，两个旋钮：把 `screen:true` 改成"弹道只造成 25% 伤害"而不是完全免疫；或降到 600 盾。
- 铁门僵尸**不能与报纸僵尸叠加**（一个僵尸只有一种护具）。要做"复合僵尸"是更大的改动。
- 图鉴提示行数已到 7 行，接近面板高度上限，再加僵尸就需要改布局。
