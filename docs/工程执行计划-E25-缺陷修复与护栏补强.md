# E25 执行计划（修四处缺陷 + 给测试基础设施补护栏）

> 日期：2026-11-25
> 起因：对整个项目的只读评审，而非某个具体 bug 报告。
> 性质：**缺陷修复 + 护栏补强**——不改玩法、不改数值、不改画面。

## 1. 结论先行

评审结论是代码质量明显高于同类项目（依赖方向单向、双随机流、端口注入、动作入口统一返回 `{ok, reason}`）。
但找到**四处真实缺陷**，其中一处玩家可直接感知；以及一处**护栏看起来覆盖了、其实没覆盖**的结构性问题。

四处缺陷全部是「注释与代码不一致」或「防御写在了错误的一层」，没有一处是架构问题。

## 2. 四处缺陷

### 2.1 光标不跟选中一起清（玩家可感知）

`src/ui/input.js` 的光标只在 `mousemove` 里计算，但清除选中有三条路径不经过它：
右键、点空地失败、以及种完/铲完/阳光不足后由动作自己清的选中。

**后果**：右键取消选中后指针仍停在 `crosshair`，玩家以为自己还在「待放置」状态。

改法：抽出 `syncCursor()`，`mousemove` / `mousedown` / `contextmenu` 三处都重算。
`mousedown` 那处是关键——必须在 `onPress` **返回之后**调用，否则「种下最后一格自动取消选中」仍然漏。

### 2.2 咖啡豆绕过阳光校验

`inspectUseCard` 的 coffee 分支不检查阳光，注释写「当前不可达」。
不可达只是这一版的巧合（`pickSlot` 已经先挡过一次），代价却是一个在悬停层看起来合法、
在提交层会扣成负数的缺口——**悬停高亮与提交共用这个函数**，豁免等于同时放行了两边。

改法：阳光与冷却检查提到分支之前，对所有卡一视同仁。咖啡豆同样花阳光，没有玩法理由让它豁免。

### 2.3 已判死的僵尸继续吃伤害

死亡动画那 0.95 秒里尸体仍在场上，爆炸与小推车会扫到它，`hp` 被扣成负数。
目前无害（渲染只按 `state==='dying'` 播动画），但等于让 `hp` 的含义随时刻漂移。

改法：`damageZombie` 入口加 dying 门并返回 `false` 表示未生效。

### 2.4 卡槽循环没有上限

HUD 按 `MAX_CARDS=8` 预留宽度，但循环遍历 `world.slots.length`。
关卡卡数一旦超过 8，多出的卡会画到铲子按钮上并被它的热点压住——**有卡却点不到**。

改法：渲染层用 `Math.min` 兜底，并把 `MAX_CARDS` 导出给测试守护。

## 3. 结构性缺口：测试清单对「没跑」和「一致」给出同样的沉默

`npm test` 用 `tests/*.test.mjs`，只匹配顶层。`tests/browser/` 下 2 个测试文件、34 条声明
不在任何单测链条里，而按路径记的清单——**对「压根没访问」和「一致」给出同样的沉默**。

`check-test-inventory` 现在除条数外还记录三样：

| 记录 | 抓的问题 |
|---|---|
| `covered`：`npm test` 实际展开到的文件集 | 某个测试文件被 glob 漏掉 |
| `browser`：`test:browser` 覆盖的文件集 | 浏览器套件被悄悄收窄 |
| `browserBaselines`：轨迹基线名单 | 基线文件被删 |

文件集合**从 `package.json` 的脚本现读**，不另抄一份 glob——否则又多一份会漂移的副本。

**实测验证**：把 `npm test` 改窄会立刻报出 24 个「脱离单测执行链」；把浏览器 glob 收窄会报出 `release-smoke` 脱离。

## 4. 顺带修的两处

1. **背景缓存只按主题失效，不按 DPR**。拖到另一块屏幕后一直贴旧分辨率的整幅位图。
   缓存键改为 `(主题, DPR)`。
2. **新增分数 DPR 冒烟**：1.25 / 1.5 两档在 boot 时的背板尺寸与画面都被验证。
   历史风险正是这一档没人测过。

## 5. 减负：轨迹基线 5 条 → 3 条

删掉 `select-l3` 与 `quiz-l3`——这两个界面没有随时间变化的绘制，
逐帧轨迹绝大部分是同一段静态面板的重复。

**删基线前的验证**：重新生成后，保留的三条与 HEAD **逐字节相同**（5054/1420/1351 行），
证明本轮改动没有动渲染。

`verify` 换成 `test:browser:baselines`：轨迹基线进 verify，完整冒烟留给发版前。
理由与当初「CI 直接跑 verify」一致——verify 是「改了什么都要跑」的门，冒烟是「发版前跑」的门。
