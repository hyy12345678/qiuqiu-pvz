## 2. 本轮明确不做

- 不做 R4 的渲染 / 输入 / 循环拆分：`main.js` 仍持有 `G`、Canvas 绘制与事件绑定。
- 不新增植物、不调数值、不改碰撞、时间步、随机流、概率阈值、实体排序与阶段顺序。
- 不把 `sunFlash` 等其余表现字段搬出 world；本轮只动方案点名的 5 个 UI 字段。
- 不把导航按钮重构成 DOM UI，也不改逻辑坐标、DPR、触屏事件组合。
- 不修「咖啡豆提交不校验阳光」这一现存小口子（见 §1）。
- 不建通用命令框架、撤销栈、快捷键系统或可扩展动作注册表。

## 4. 动作 API

| 接口 | 责任 | 失败原因（示例） |
|---|---|---|
| `inspectUseCard(world, slot, row, col)` | **只读**：冷却、占格、咖啡豆目标、阳光；同时给出 `kind` | `no-slot / cooling / occupied / invalid-target / not-enough-sun` |
| `useCard(world, slot, row, col)` | 提交：再次调用只读判断，成功后一次性种植或唤醒、扣费、进入冷却 | 同上 + `wrong-state / paused / out-of-bounds` |
| `pickSlot(world, ui, i)` | 选卡 / 再点取消；余额不足闪阳光盒 | `cooling / not-enough-sun` |
| `toggleShovel(world, ui)` | 切换铲子并清除选卡 | `wrong-state / paused` |
| `pressCell(world, ui, row, col)` | 格子按下：铲除优先，其次当前选卡 | `empty / no-selection` |
| `collectSun(world, x, y)` | 倒序命中未飞行的阳光，标记为飞行 | `no-sun` |
| `chooseLevel(world, ui, li)` | 校验锁定后进入选卡并清除选择 | `locked / bad-level` |
| `togglePause(world)` | 仅 play 状态可切换暂停 | `wrong-state` |
| `removeSlot` / `pickTeamPlant` | 选卡界面的卡槽增删 | `no-slot / team-full` |

约定：

- `ok:true` 不带原因；`ok:false` 必带 `reason`，测试依赖这些字符串。
- **失败零副作用**：不扣阳光、不推进冷却、不改目标格、不取消选卡；唯一例外是 `pickSlot` 余额不足时点亮 `sunFlash`，与现状一致。
- 动作层接管原先散在 `main.js` 的反馈音：`click / select / error / dig`；种植与唤醒音仍由实体函数经端口发出。
- `answerQuiz` 改为返回 `{ ok, correct }` 或 `{ ok:false, reason }`；计时与进入战斗仍由 `updateQuiz` 负责。

### W3 主入口改接

- `main.js` 创建 `const UI = createUI()`；所有 `G.mouse/hoverCell/sel/shovel/hotspots` 换 `UI.*`。

- `handlePress` 顺序保持：热点（倒序）→ 阳光（倒序）→ 格子。
- 键盘 1–8 走 `pickSlot`，Esc 走 `clearSelection`，P 走 `togglePause`，右键清除选择。
- `headless_test.js` 与 `world-isolation.test.mjs` 改读 `UI.*` / `createUI()`。

**验收**：模块冒烟 A–I 全通过；触屏与鼠标仍共用同一个 `handlePress`。

### W4 测试

新增 `tests/actions.test.mjs`，覆盖：

| 情形 | 断言 |
|---|---|
| 阳光不足 / 冷却中 / 占用格 | `useCard` 失败；格子、阳光、冷却、选卡全不变 |
| 咖啡豆点空格 / 清醒植物 / 非法格 | 失败；不扣费、不冷却、不取消选卡 |
| 咖啡豆点睡眠蘑菇且阳光足够 | 唤醒、扣费、冷却、取消选卡各发生一次 |
| `inspectUseCard` | 前后状态快照一致（只读证明） |
| 铲子空格 / 有植物 | 空格不清铲子；有植物时移除、粒子、清铲子、发 `dig` |
| 收阳光 | 倒序优先、飞行中的阳光跳过、暂停时拒绝 |
| 暂停 / 非战斗 | 战斗动作失败；`togglePause` 与选关仍按现状工作 |
| 选关 | 锁定关卡拒绝且不改状态；合法关卡进入 select 并清除选择 |
| 同一逻辑格 | `pressCell` 同一输入得到同一结果；发布冒烟已覆盖鼠标与触屏等价 |
| UI 隔离 | 两个 `createUI()` 的容器、鼠标对象与热点表互不共享 |
| 热点优先级 | 后注册的同区域热点先命中 |
